## Как проверить работу:
1. Клонировать репозиторий
2. Установить зависимости: `poetry install --no-root`
3. Применить миграции: `poetry run python manage.py migrate`
4. Запустить сервер: `poetry run python manage.py runserver`
5. Проверить:
   - Главная страница: http://127.0.0.1:8000/
   - Страница контактов: http://127.0.0.1:8000/contacts/
   - Админка: http://127.0.0.1:8000/admin/ (логин: Виктор)
